# Lenovo ThinkCentre M90q Gen 5 - Customer Guide

Customer delivery pages for the Lenovo ThinkCentre M90q Gen 5 Tiny (MTM 12THS0EW00) with ThinkVision E20-30 monitor, prepared by Abans PLC.

- **User Guide** - `index.html` - stage-style interactive guide: set up in 5 steps, ports explorer, how to use, good habits, care, help and full specifications.
- **Presentation** - `presentation.html` - 10-page customer presentation.

Both are single self-contained HTML files (photos embedded, work offline).
